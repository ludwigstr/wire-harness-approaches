Method details

Pipeline

  1. Twin fit (physworld_mpm_fit.py, elastoplastic, NVIDIA Warp). Global stage: homogeneous Young's modulus E, density ρ, board friction μ, Poisson ratio ν and yield stress. Local stage: per-particle E, ρ and μ on about 23k particles per clip; ν and yield stay global. Loss as in the paper: Chamfer + 0.1 × smooth-L1 track loss over all frames.
  2. Demonstrations (physworld_mpm_demos.py --n 40): 40 demos per clip generated from the twin.
  3. GNN world model (physworld_mpm_gnn.py): trained on the demos with the multi-step loss of Eq. 8, noise on the history and on Φ.
  4. Φ fine-tuning: per-node (log E, log ρ), 2 × 16 × 4 = 128 values per clip, fitted on the real clip with the network frozen. Objective: open-loop rollout MSE + Chamfer; Φ stays within ±1.5 (log) of the twin's value.
  5. Evaluation: 5-frame warm-up, then open loop from the measured end motions, ends pinned.

Deviation from the paper

  • On the 36 clips one pooled GNN is trained on the demos of all clips; the paper trains one per scene. Φ is still fitted per clip.

Per-node Φ along each cable

Φ holds 2 values per node (stiffness E and density ρ) for the 16 nodes of the 4 cables: 128 per clip. Each clip starts from its twin’s values and is fine-tuned on the real clip with the network frozen. Shown: the 14-clip run (one GNN per clip, physworld_mpm/data/gnn), the run whose per-node Φ is in the repository.
