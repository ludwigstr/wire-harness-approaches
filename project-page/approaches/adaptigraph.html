A material-conditioned graph-based neural dynamics model (GBND) with one physical property variable φ, estimated few-shot on each real cable.

Learns from
Analytical mass-spring simulator (the paper uses NVIDIA FleX) + real fine-tuning
Physical properties
φ = normalised mean log bending stiffness, one per cable
Adapted on real clip
φ from the 5 warm-up frames, 29-point grid over [−0.2, 1.2]
Model
GBND, 0.51 M weights, 4 rounds of message passing
Scored
16 nodes, ends pinned, frames 5…T−1
36-clip result
29.42 mean / 27.83 median

The graph

  • Vertices: the 16 cable nodes with a 3-frame history as displacements (translation-equivariant), particle type (object / end effector), material, and φ.
  • Edges: chain neighbours + all pairs within 12 cm.
  • Decoder: every node's displacement; the two driven end nodes are set by the action.

Pipeline

  1. Simulator data (make_dataset_real.py --mode seq): every chain starts from a real tracked frame; the ends follow the real end path with speed-only variation ×0.8–1.2. One transition is one 0.25 s frame with the 4 preceding frames as history. Same parameter ranges as Caporali.
  2. Simulation training: 20 epochs, one-step MSE (best validation one-step error 1.26 mm on the 14-clip data).
  3. Real fine-tuning (not in the paper): the real frame transitions, 60 epochs, φ fixed at 0.5 because the real stiffness is unknown.
  4. Evaluation: φ per cable from the first 5 frames (the paper uses Bayesian optimisation; for one scalar a dense grid is equivalent), then open loop with the model's own history and the measured ends.
