An MLP with FiLM conditioning learns the one-step response of an analytical mass-spring model from synthetic data only. On a real clip the network stays frozen and the model parameters are estimated online.

Pipeline

  1. Synthetic data (make_dataset_real.py --mode step --stride 1): every chain starts from a real tracked cable state; the ends follow the real end paths with speed-only variation ×0.8–1.2. One transition is one video frame: 0.15 s of end motion plus 0.1 s of settling.
    • Sampled: m 0.02–0.10 kg, k_b 0.2–3.0 N·m/rad, k_d 5–40 N·s/m, k_c 0.05–0.4 N/node
    • Rest shape: frame-0 turning angles ×0.6–1.2
  2. Training: the paper's Fig. 3 FiLM MLP, 25 epochs (AdamW + OneCycle, MSE on node positions). On the 36 clips the training data is built from the 36 clips.
  3. Online estimation: m, k_b, k_d per cable start at 0.04 / 1.0 / 20; each frame is forecast before it is used for one Adam step on the parameters, so the score never sees the frame it predicts. The rollout is open loop from frame 0 with the measured ends.
