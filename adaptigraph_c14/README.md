# AdaptiGraph (Zhang et al. 2024) trained on simulator data from the 14 clips: snapshot of the current scripts

This is a snapshot of the AdaptiGraph pipeline from the main project (Wire_Model_S). It was copied as-is on
2026-10-29 so colleagues can use it. **It has not been adapted to this repo or tested here.** The paths are
still those of the main project; the ones to change are listed below.

It replaces `approaches/10_adaptigraph.py` (24.4). That model was trained on simulator data built from the
103 X-Planar clips with spatially scaled end motions (x0.6-1.4). Here the simulator data is built from the
14 evaluation clips, and the ends only vary in speed.

## Method

1. `scripts/make_dataset_real.py --mode seq --tracks data/tracks14 --chain-len 10 --speed 0.8 1.2 --chains 30000`
   builds the synthetic training data from the analytical mass-spring simulator (`wire_model/dlo_model.py`).
   - Every chain starts from a real tracked frame of one of the 14 clips (all 56 cable trajectories).
   - The two ends follow that trajectory's real end path, with speed-only variation x0.8-1.2 (one shared
     time warp per chain) and no spatial scaling.
   - One transition is one 0.25 s video frame, with the 4 preceding frames as history.
   - Sampled parameters: m 0.02-0.10 kg, k_b 0.2-3.0 N m/rad (phi 0..1), k_d 5-40 N s/m,
     k_c 0.05-0.4 N/node. The rest shape is the frame-0 turning angles x0.6-1.2.
   - `--chain-len 10` so that the 19-frame clip 102713 qualifies. With 12 it would be dropped silently.
   - Result: 288,779 transitions.
2. `scripts/adaptigraph_train.py --kb-range 0.2 3.0 --epochs 20` trains the property-conditioned graph
   dynamics model (0.51 M weights) on the simulator data. Best validation one-step error: 1.26 mm.
3. `scripts/adaptigraph_train.py --real --init ... --epochs 60` fine-tunes it on the 2,712 real frame
   transitions of the 14 clips (`data/transitions_seq_all.pt`), with phi fixed at 0.5.
4. `scripts/adaptigraph_eval.py --tracks data/tracks14` evaluates. phi is estimated per cable from the
   5 warm-up frames (29-point grid), then the rollout runs open loop with the measured ends.

The full chain with the exact arguments is `scripts/run_train_on_14.sh` (its `adaptigraph` function).
The same script also rebuilds Caporali et al. (see `caporali_et_al/`).

## Result on the 14 clips

| Model | Mean (mm/node, after 5 warm-up frames) | Median |
|---|---|---|
| **Simulator data from the 14 clips + real fine-tuning** | **21.09** | **17.83** |
| Simulator data from the 14 clips only | 28.38 | 27.07 |
| Previous: X-Planar data, scaled motion, + real fine-tuning | 24.42 | |

The fitted phi lies in -0.2..1.15; 22 of 56 cables are on the lower bound -0.2.

Wall clock: dataset 4.7 min, simulator training 8.3 min, fine-tuning 14 s (1 GPU).

Shipped: `checkpoints/` (simulator-only and fine-tuned), `results/` (per-clip results and logs),
`data/transitions_seq_all.pt` (the real fine-tuning transitions). The simulator dataset (258 MB) is not
shipped; it is regenerated by step 1 (seed 0).
